# Credits and provenance

Developer / publisher name supplied by the user: Sandeep Kumar.

The game contains 18 original SVG compositions created for this project. The reference and canvas share a single geometry definition. UI, favicon and listing artwork candidates are project-created. Sound effects are generated using Web Audio oscillators; there are no sampled recordings. Fonts use the device's system fonts and are not redistributed. No art or code from another coloring game is included. General interaction references include color selection, picture collections and relaxing pacing seen in established coloring games.

Vite and Playwright are development/test tools and are not shipped as game runtime dependencies. Their dependencies and license notices are retained under node_modules when installed. The YouTube SDK is loaded from the official endpoint only in the platform build, not copied into the release.
